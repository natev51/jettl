## Installation

[Install on VIPM](https://www.vipm.io/package/nathan_davis_lib_jettl/)

### Palette

1. Open the palettes.
2. `Data Communication` → `jettl`

### Tools

1. `Tools` pull-down menu
2. `jettl Tools`

### Examples

In LabVIEW:

1. `Help` pull-down menu
2. `Find Examples`
3. `Search`
4. Enter keyword(s): `jettl`

In VIPM:

1. Search `jettl`
2. Right click `jettl`
3. `Get Info`
4. `Show Examples`
